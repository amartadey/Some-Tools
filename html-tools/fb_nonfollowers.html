Facebook Non-Followers Finder

Find out who you follow that doesn't follow you back — no third-party apps needed.

STEP 1 — FOLLOWING PAGE

Open your Facebook /following page. Scroll all the way to the bottom to load every profile. Then open the browser console (F12 → Console tab) and run Script A below.

STEP 2 — FOLLOWERS PAGE

Open your Facebook /followers page. Scroll to the bottom again to load all profiles. Open the console again and run Script B below.

STEP 3 — COPY OUTPUT

Each script will print a JSON array in the console. Copy both outputs and paste them into the boxes below to see who isn't following you back.

STEP 4 — SEE RESULTS

Hit Find Non-Followers and this tool will compare both lists and highlight every profile that's in your Following list but not in your Followers list.

⚠️ Facebook frequently changes its page structure. If a script returns an empty array, Facebook may have updated its HTML. The scripts below target the most common current selectors but may need updating. Never run scripts from unknown sources — you can read every line here before using.

SCRIPT A — Run on /following page

(function() {
  // Scroll helper — loads dynamic content
  // Run this on: facebook.com/[yourpage]/following
  // After scrolling to the bottom manually

  const links = new Set();

  // Try multiple selector strategies Facebook uses
  const anchors = document.querySelectorAll('a[href]');

  anchors.forEach(a => {
    const href = a.href;
    // Match profile-style URLs: facebook.com/someusername
    // Exclude nav links, ads, groups, pages meta links
    if (
      href.includes('facebook.com/') &&
      !href.includes('/groups/') &&
      !href.includes('/pages/') &&
      !href.includes('/events/') &&
      !href.includes('/hashtag/') &&
      !href.includes('/help/') &&
      !href.includes('/policies/') &&
      !href.includes('/login') &&
      !href.includes('/photo') &&
      !href.includes('/video') &&
      !href.includes('/posts/') &&
      !href.includes('/permalink/') &&
      !href.includes('/following') &&
      !href.includes('/followers') &&
      !href.includes('facebook.com/?') &&
      a.closest('[role="listitem"], [data-pagelet], .x1yztbdb, .x78zum5')
    ) {
      // Normalise URL — strip query params & trailing slashes
      try {
        const url = new URL(href);
        const clean = url.origin + url.pathname.replace(/\/$/, '');
        if (clean !== 'https://www.facebook.com' && clean.split('/').length === 4) {
          links.add(clean);
        }
      } catch(e) {}
    }
  });

  const result = [...links];
  console.log('%c✅ FOLLOWING list (' + result.length + ' profiles found)', 'color:#4f8ef7;font-weight:bold;font-size:14px');
  console.log(JSON.stringify(result, null, 2));
  copy(JSON.stringify(result)); // Auto-copies to clipboard in Chrome
  console.log('%cAuto-copied to clipboard! Paste into the tool.', 'color:#34d399');
})();

🧩 The Chrome Extension automates all scrolling — no manual scrolling or console scripts needed. Install it once and just click a button on the Facebook page.

INSTALL (takes 1 minute)

  1. Download and unzip the file
  2. Open Chrome → go to chrome://extensions
  3. Toggle Developer Mode ON (top-right corner)
  4. Click Load unpacked → select the fb-nonfollowers-extension folder
  5. The extension icon appears in your toolbar ✅

HOW TO USE

  • Go to your Facebook /following page → click the blue 🔍 Scrape Following button (bottom-right) and wait for auto-scroll to finish
  • Go to your /followers page → click 🔍 Scrape Followers and wait
  • Click the extension icon in Chrome toolbar → hit Compare Lists
  • See every profile that doesn't follow back, with clickable links
